# 神经网络与深度学习

## 深度学习学习路径（知识体系）

**张量与运算 → 自动微分与最小训练闭环 → 网络构件与损失 → 优化与调参 → 泛化与正则 → CNN（空间）→ RNN（序列）**

### 1. 数值表示与张量运算

深度学习框架底层用**多维数组（张量）**存放数据与参数。先要掌握：怎样创建张量、指定数据类型、与 NumPy 互转（注意共享内存）、逐元素运算与**矩阵乘法**的区别、按维度归约（求和、均值等）、索引与切片、**变形与换维**（`reshape`/`view` 与内存连续性、`transpose`/`permute`）、沿维度拼接（`cat`/`stack`）。这是后续一切模型与前向、反向传播的底座。

### 2. 自动微分与“最小训练闭环”

神经网络训练依赖**梯度**。要理解：**计算图**、`requires_grad`、**反向传播** `backward()`、梯度在迭代中的**累加**与**清零**，以及 **`detach()`** 在“脱离梯度追踪”（例如转 NumPy）时的作用。在此基础上，把“线性模型 + 均方误差”跑通：**前向 → 算损失 → `backward` → 更新参数**，再过渡到 **`nn.Linear`**、**`TensorDataset`/`DataLoader`**、**`optim.SGD`** 以及 **`optimizer.zero_grad()` → `loss.backward()` → `optimizer.step()`** 的标准三步循环——这就完成了从数学公式到 PyTorch 训练模板的第一步。

### 3. 网络构件：激活、初始化、模块化建模与损失函数

单层线性变换只能表达线性关系；**激活函数**引入非线性，使网络能拟合复杂映射。需要熟悉常见激活（如 Sigmoid、Tanh、ReLU）及多分类输出常用的 **Softmax**（与交叉熵的配合）。**参数初始化**影响收敛与稳定性（如 Xavier / Kaiming 与激活函数的常见搭配）。用 **`nn.Module`** 把多层组合成模型，在 **`forward`** 里串联计算图。针对不同任务选择**损失函数**：回归常用 MAE/MSE/Smooth L1；多分类常用 **交叉熵**（注意：`CrossEntropyLoss` 与 logits、Softmax 书写习惯的差异）；二分类常用 BCE 或 **BCEWithLogitsLoss**。

### 4. 优化算法与学习率策略

**梯度下降**及其变体解决“朝哪个方向、迈多大步更新参数”。要理解学习率过大或过小带来的现象，以及 **动量**、**指数滑动平均**思想（与 Adam 等算法中的一阶、二阶矩估计相呼应）。实践中还会用到 **SGD（含 momentum）**、**AdaGrad**、**RMSprop**、**Adam** 等优化器。仅调优化器往往不够，还需要**学习率调度**（随训练进程衰减或按里程碑调整），以平衡前期探索与后期精细收敛。

### 5. 泛化与训练技巧：正则化与归一化

复杂模型容易在训练集上“记答案”——**过拟合**。手段包括：**Dropout**（训练时随机失活）、**L1/L2** 权重惩罚（课程中常与前述损失或优化结合讨论）、以及 **Batch Normalization**（标准化再缩放平移，稳定中间层分布、常有利于深层网络训练）。同时要在工程上区分 **`model.train()`** 与 **`model.eval()`**（影响 Dropout、BN 等行为）。表格类特征上的**多层全连接（MLP/ANN）分类**是把这些组件串起来的典型练手问题。

### 6. 卷积神经网络（CNN）：局部性与空间结构

图像等数据具有**空间局部性**与**平移相关**的先验。**卷积层**用局部感受野扫过整幅特征图，**池化**降低空间分辨率、增大感受野，最后通过展平与全连接完成分类或回归。典型流程：**Conv → 激活 → Pooling** 堆叠，再接全连接与任务损失。计算机视觉入门常配合公开小图像数据集（如 CIFAR-10）做图像分类实验。

### 7. 循环神经网络（RNN）：序列与上下文

语音、文本、时间序列等**有序数据**往往依赖前后文。**词嵌入**把离散符号映射为稠密向量；**RNN**（及后续课程中常见的 LSTM/GRU）通过隐藏状态在时间步之间传递信息，适合建模序列依赖。语言建模、文本生成类任务常采用 **Embedding + RNN + 输出层（如对词表大小的 logits）** 的结构，并用交叉熵等损失训练。
